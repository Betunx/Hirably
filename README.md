# Hirably - Landing Page

Angular 17 + Tailwind. Gestor de paquetes: **pnpm** (no usar npm/yarn).

## Instalación
```bash
pnpm install
```

## Desarrollo
```bash
pnpm start
```

## Build
```bash
pnpm run build:prod
```

## Deploy
```bash
vercel --prod
```

## Ramas
- `main` — producción.
- `preProduction` — integración/preview; se promueve a `main` vía Pull Request.
